## Camel case
El **Camel Case** (o "notación de camello") es un estilo en el que la primera letra de cada palabra se escribe en mayúscula, excepto la primera palabra. Este estilo es común en muchos lenguajes de programación para nombrar variables y funciones.

> Ejemplo
> ```python
> def calcularSuma(): 
> pass
>```

[Wikipedia Camel case](https://es.wikipedia.org/wiki/Camel_case)
## Pascal Case
El **Pascal Case** es similar al Camel Case, pero en este caso, la primera letra de cada palabra, incluida la primera, se escribe en mayúscula. Este estilo se utiliza a menudo para nombrar clases.
> Ejemplo
> ```python
> class MiClaseEjemplo: 
> pass
>```
## Snake Case

El **Snake Case** utiliza guiones bajos para separar las palabras y todas las letras son minúsculas. Este estilo es común en Python y se utiliza para nombrar variables y funciones.
> Ejemplo
> ```python
> def calcular_suma(): 
> pass
>```
## Kebab Case

El **Kebab Case** es similar al Snake Case, pero utiliza guiones en lugar de guiones bajos. Este estilo no es común en la programación, pero a veces se utiliza en URLs o nombres de archivos.
> Ejemplo
> ```text
> calcular-suma
>```
## Upper Case

El **Upper Case** se utiliza para constantes y se escribe en mayúsculas, separando las palabras con guiones bajos. Este estilo es común en muchos lenguajes.
> Ejemplo
> ```python
> MAXIMO_VALOR = 100
>```

## Upper Camel Case
UpperCamelCase, también conocido como PascalCase, es un estilo de escritura en el que se combinan varias palabras sin espacios y la primera letra de cada palabra se escribe en mayúscula.
> Ejemplo
> ```python
> EjemploDeUpperCamelCase
> ```
